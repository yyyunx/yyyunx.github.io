## Course record

The midterm explores cellular automata through Conway’s Game of Life. The final artificial ecosystem combines movement, food, reproduction, aging, and population-balancing rules.

## Technical focus and scope

These projects study rule-based simulation and emergent behavior rather than trained machine-learning models. The README calls the work C, while the ecosystem source also contains C++ standard-library facilities and syntax. This index therefore labels the work C / C++ rather than inferring language from the extension alone.

The ecosystem source identifies a course group as its author. Personal responsibilities are not inferred here, and a planned GUI extension is not presented as completed.
