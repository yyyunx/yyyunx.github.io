## Course record

A collection of data structure exercises and foundational algorithm implementations, presented as a learning record rather than a large product case study.

## One comparison: the Knight’s Tour

HW3 searches iteratively with a custom stack, while HW4 uses recursive backtracking. Both solve the same problem but store search state differently, providing a concrete way to compare an explicit stack with the call stack.
