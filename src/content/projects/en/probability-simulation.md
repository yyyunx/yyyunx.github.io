## Course record

Python / NumPy simulations compare empirical results with theory for waiting times, order statistics, covariance, Poisson splitting, and multinomial distributions.

## Implementation and limits

Problems live in separate folders. Public code exposes random seeds, sampling, and statistical calculations. This note does not present README configuration as a fresh execution result.

Monte Carlo estimates depend on sample size and randomness. Agreement with theory is not a mathematical proof and does not establish behavior for untested distributions.
