## Course record

Eight exercises retain their original interfaces and code. They progress from DOM interactions, timers, and localStorage to asynchronous data, Canvas, speech, maps, and pose interaction. A deployed index links to the individual applications.

## Implementation scope

The collection includes a Pomodoro timer, to-do list, sticky notes, information board, Canvas game, English practice, AQI map, and pose-controlled game. Source and test documentation remain in the public repository; this page serves as a concise coursework index.

## Usage limitations

Camera, speech, and location features depend on browser support, HTTPS, permissions, and external services. Synthetic-camera tests do not establish real pose accuracy. Demonstration fallback information is not live data; AQI uses an official snapshot fetched during deployment.
